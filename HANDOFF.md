# Ferrari of Puerto Rico website: developer and agent handoff

A static HTML site for the official Ferrari dealer in San Juan, generated by a
Node build script and hosted on GitHub Pages. Read this first, then
`v3/README.md` (the full decision log) before changing a page.

Written 19 Nov 2026, at commit `d0289a9`.

## Build

> **Every `.html` page is generated.** Never edit one by hand: the next build
> overwrites it. Change the `_*.html` partials, `build.mjs`, the CSS or the JS,
> then rebuild.

```
cd v3 && node build.mjs
```

- **Run it from inside `v3/`.** Run from the repository root, it writes v3
  output into the root site.
- Node only, no packages to install. Tested with Node 24.
- `build.mjs` assembles each page from the shared chrome (`_head.html`,
  `_header-pr.html`, `_mobilemenu-pr.html`, `_footer-pr.html`, `_popups.html`,
  `_tail.html`) plus the page's own partial or template. It writes
  cache-busting `?v=` strings from file modification times, so a rebuild
  touches every page.
- The root site has its own `build.mjs`. It currently stops on
  `index-v1.html` because `_header-pr-v1.html` is not in the repository;
  `index.html` is still written.
- Local preview: `cd v3 && python3 -m http.server`, then open
  http://localhost:8000/.

## Forms: where to connect a backend

No form sends anything yet. Each handler validates in the browser, calls
`preventDefault()` and shows "Sending to be confirmed — no service is connected
to this preview yet." Replace that line in each handler with the real request.

| Form | Where | Handler |
|---|---|---|
| Value your Ferrari (5 blocks, image upload up to 12) | `sell-or-consign.html#value`, form `#pr-sell` | `js/sell.js` |
| Programme interest / request information | Corso Pilota, Challenge, Club Challenge, CCGT, 296 GT Modificata, XX, Pedigree, Owner's Manuals, Hybrid, Event Schedule; form `#pr-interest` | `js/interest.js` |
| Demo drive | `demo-drive.html`, form `#pr-drive` | `js/drive.js` |
| Inquire / Schedule test drive / Text to phone | vehicle pages and home tiles (drawers and popups) | `js/pop.js` |

The Value your Ferrari form reproduces cauleyferrari.com/value-your-trade/:
field names (`year`, `make`, `model`, `vin`, `mileage`, `fname`, `email`,
`message` …), order and required stars. Selected images are kept in memory by
`js/sell.js`; its Upload button is the place to send them.

## Inventory

The stock is the dealer's own, read from ferraripuertorico.com on 22 Oct 2026:
9 cars in `v3/data/inventory.json`, up to 30 photos each in
`v3/img/inventory/<stock>/`. `build.mjs` writes the list page and one page per
car from that file, so a car removed from the JSON loses its page on the next
build. Three cars have only "photos coming soon" frames and three have no price
("Price to be confirmed"). A live feed should replace the JSON file in the
same shape.

## House rules for new pages

- **Invent nothing.** A fact without a source shows as "to be confirmed".
  Content sources in this order: the dealer's current site, cauleyferrari.com,
  ferrari.com.
- **Ferrari's copy stays verbatim; other dealers' copy never does.** Use
  another dealer's page for facts only, and write the text in our own words.
- **One hero.** Every hero is Ferrari Approved's `.fa-hero`, unchanged. Choose
  the photograph for the hero; never resize the hero for a photograph.
- **No photograph appears twice** on the site. Note the source of each new image.
- **Marker, then 24px, then the heading** in every section.
- **Dropdowns are Ferrari's f-dropdown** (`js/dropdown.js`), never the OS list.
  Exception: the Value your Ferrari form uses native selects, as Cauley's does.
- **Forms stay on the page.** The default is the enrolment form in
  `css/form.css` (`.pr-fform`). Sell or Consign uses Cauley's boxed form
  (`css/vform.css`); Demo Drive keeps its own.
- **Smooth scroll is Lenis**, built in from the start, not constructed under
  reduced motion.
- **Nothing the dealer has to maintain**: no countdowns, live clocks or
  "coming soon" blocks. The client keeps only Event Recaps (the blog) and the
  Gallery.
- **AI-restored images are recorded.** Some Ferrari photos served at low
  resolution were upscaled ×2 (Topaz Precision via fal.ai, restoration only);
  provenance is in `v3/README.md`.

## Deploy

1. Build from `v3/` and check the pages locally.
2. Commit and push to `main`. GitHub Pages publishes in about a minute.
3. Hard-refresh the live page (Cmd+Shift+R) to get past the cache.

Keep pushes small: about 800 files in one push timed out on Pages; around 400
deploy in under a minute.
